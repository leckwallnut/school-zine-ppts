# Design system

Use a 16:9 canvas. For an existing lesson with a required slide size, fit these compositions to that size.

| Color | Hex | Use |
| --- | --- | --- |
| Ink indigo | #181936 | Type on cream, dark surfaces and outlines |
| Warm cream | #FFF0C9 | Reading surfaces and type on indigo |
| Marigold | #FFBD35 | Important cues and brief section turns |
| Coral | #F9634A | Accents and grouping |
| Mint | #69BBA9 | Accents, grouping and short native highlights |

Use Arial throughout, with bold titles and regular body text. Start at 52 pt for a deck title, 38 pt for a slide title and 26 pt for the main body. Table and diagram labels can use 22–24 pt when clear. Reserve smaller text for optional credits. If Arial is unavailable, use one available sans serif with the needed character coverage. Check type in the actual renderer.

The illustrations carry the gouache, ink contours, paper grain and halftones. Keep text on the quiet fields. Use cream or indigo paper for sustained reading and instructions. Use the brighter page turn for a major transition. For a mature audience, pair quiet surfaces with a prop or an unoccupied scene where the topic calls for it.

On a 1280 × 720 working canvas, the pilots use roughly 72 px outer margins. A full-width page fits about 60–70 words at 28 pt in the library. A split column usually fits 25–40 words at 26 pt. These are planning estimates. Split long passages or resize the composition before shrinking type. Use editable text and drawing objects for all instructional material.

Vary text placement, reading order and picture scale as the lesson moves between explanation and participation. Reuse the same composition when it helps students compare repeated examples or follow a paired prompt and reveal.
